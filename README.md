✨ Project Overview
```{=html}
</h2>
```
*TravelEase* is a full‑stack MERN vehicle rental system where users can
explore available vehicles, view details, and authenticated users can
add, update, or manage their own listings. This project ensures secure
operations, smooth UI interaction, and optimized user experience with
modern tooling.

------------------------------------------------------------------------

```{=html}
<h2 align="center">
```
🚀 Features
```{=html}
</h2>
```
-   🚗 *Add, update, delete, and view vehicles*\
-   🔐 *Firebase authentication (Login / Register / Logout)*\
-   💰 *Price‑based and category‑based vehicle browsing*\
-   📍 *Location‑based filtering*\
-   🖼 *Image‑based vehicle presentation*\
-   ✨ *Toast notifications using React Toastify*\
-   🔒 *Protected routes for user‑owned vehicles*\
-   📱 *Responsive UI with Tailwind & DaisyUI*\
-   🧭 *Dynamic page titles via React Helmet Async*

⚙ Installation & Setup
```{=html}
</h2>
```
1.  `<strong>`{=html}Clone Frontend:`</strong>`{=html}

```{=html}
<!-- -->
```
    git clone https://github.com/ei-shadi/TravelEase.git
    cd TravelEase
    npm install

2.  `<strong>`{=html}Clone Backend:`</strong>`{=html}

```{=html}
<!-- -->
```
    git clone https://github.com/ei-shadi/travelease-server.git
    cd travelease-server
    npm install

3.  `<strong>`{=html}Create .env in /server:`</strong>`{=html}

```{=html}
<!-- -->
```
    MONGODB_URI=your_mongodb_uri
    FIREBASE_ADMIN_KEY=your_firebase_admin_sdk_json

4.  `<strong>`{=html}Start Local Servers:`</strong>`{=html}

```{=html}
<!-- -->
```
    cd TravelEase
    npm run dev

    cd travelease-server
    node index.js
